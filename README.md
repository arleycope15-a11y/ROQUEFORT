## Character reference

The approved Roquefort master artwork supplied by Arley is the canonical visual reference for every future Roquefort asset. Preserve the camo cap, scruffy gray/brown fur, pink ears/nose/tail, body proportions, orange/black graphic energy, and especially his skeezy expression/personality.

**Do not substitute a generic rat. Do not make Roquefort cuddly.**
